# DoggoGallery

An interactive web app that fetches random dog images with a single click. Explore a variety of dog breeds and enjoy adorable snapshots.

## Technologies Used

- HTML
- CSS
- JavaScript
- Axios library for HTTP requests

## Usage

1. Click the "Click here to get image" button.
2. Watch as a new random dog image appears on the screen.
3. Enjoy the cuteness!
